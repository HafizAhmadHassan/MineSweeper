# Minesweeper

A **Minesweeper** game built as the final assignment for an **Object-Oriented Analysis and Design** course, written in **Java**.

## Overview

Implements the classic Minesweeper game, applying object-oriented design principles — separation of concerns between the board model, game logic, and UI.

## Features

- Classic Minesweeper gameplay (flags, reveals, mines)
- Object-oriented design

## Tech Stack

Java, OOP / OOAD.

## Status

Completed course final assignment.
